# CodeStory

Premium website for a web development agency.

## Goal
Build a production-ready, premium, bilingual website with a private owner-only admin dashboard.

## Stack
- Next.js 15
- React 19
- TypeScript
- Tailwind CSS v4
- shadcn/ui
- Framer Motion
- GSAP
- Lenis
- Supabase
- Supabase Auth
- Supabase Storage
- React Hook Form
- Zod
- Zustand

## Rules
- No Laravel
- No separate backend project
- Use reusable components
- Prefer Server Actions
- Focus on performance, SEO, accessibility, and conversion

## Phases
1. Foundation
2. Design System
3. Home Page
4. Services
5. Portfolio
6. Pricing
7. About
8. Contact
9. Admin Dashboard
10. SEO and Performance
